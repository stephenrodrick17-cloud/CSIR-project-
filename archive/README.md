# Archive (Pre-Correction Artifacts)

These files reflect the pipeline BEFORE the discovery/validation data-leak fix documented in the main README (Section 8). 

They are preserved here for scientific transparency and as a methods case study demonstrating rigorous data-leak detection and remediation, not for use in any current results or figures.

## Contents
- `pan_fibrotic_core_genes_PRE_FIX_175genes.csv`: The initial 175-gene intersection list (contained validation samples in liver discovery set GSE77627).
- `upset_plot_4organs_PRE_FIX.png`: Upset plot based on the pre-fix 175-gene overlap.
- `venn_4organ_region_counts_PRE_FIX.csv`: 4-organ Venn region counts for the pre-fix 175-gene pipeline.
- `pan_fibrotic_analysis_PRE_FIX.py`: The original analysis script before dataset separation.
